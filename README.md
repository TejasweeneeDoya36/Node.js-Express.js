This handles the backend part of the project. It enables database connection, fetch API, logger middleware, static file middleware and handles error messages as well.

Prerequisites:
Before you begin, ensure you have met the following requirements:

1.Install the latest version of Node.js and npm
2.Clone the repository
3.Navigate to the project directory
4.Install the necessary dependencies
5.Start the server

Technologies used:
1. Node.js
2.Express.js
3.CORS
3.Mongodb
4.Nodemon
